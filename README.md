## 🚀 One-Click Deployment to GitHub & Vercel

### Step 1: Export to GitHub from AI Studio
1. In the **Google AI Studio** workspace header, click the **Export** or **GitHub** button.
2. Select **"Export to a GitHub Repository"**.
3. Choose your GitHub account and name the repository `ochuru-web-studio`.
4. Click **Create & Push**.

### Step 2: Deploy to Vercel
1. Log in to [vercel.com](https://vercel.com) with your GitHub account.
2. Click **"Add New..."** > **"Project"**.
3. Select the `ochuru-web-studio` repository.
4. Vercel will automatically detect the settings:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. (Optional) In **Environment Variables**, add:
   - `GEMINI_API_KEY` = your Google Gemini API key from [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
6. Click **Deploy**!

Your custom landing page will be live instantly on your Vercel domain (e.g. `ochuru-web-studio.vercel.app`).
